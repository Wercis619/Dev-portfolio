# 📐 Geometric Shapes Calculator

## About the Project

**Geometric Shapes Calculator** is a Python application designed to perform geometric calculations and visualize two-dimensional shapes and three-dimensional solids.

The project combines mathematical calculations with a graphical user interface and visual representations of geometric objects.

It was developed to practice **Object-Oriented Programming (OOP)**, GUI development, mathematical algorithms, and working with Python libraries.

## Features

- Geometric calculations for 2D shapes and 3D solids
- Area and perimeter calculations
- Surface area and volume calculations
- Graphical user interface using Tkinter
- Visualization of geometric objects using Matplotlib
- 2D and 3D graphical representations
- Object-Oriented Programming (OOP)

## Technologies

- **Python** – application logic and mathematical calculations
- **Tkinter** – graphical user interface
- **Matplotlib** – geometric visualizations
- **OOP** – organization of application components
- **Git / GitHub** – version control

## Application Architecture

The application combines three main components:

**1. Geometric Calculations**

Responsible for mathematical operations based on the dimensions of geometric objects.

**2. Graphical User Interface (Tkinter)**

Provides an interface for interacting with the application and displaying calculation results.

**3. Visualization (Matplotlib)**

Provides graphical representations of geometric objects, including three-dimensional visualization.

## Object-Oriented Programming

The project focuses on applying object-oriented programming concepts to geometric calculations.

The main concepts include:

- Classes and objects
- Attributes and methods
- Organizing mathematical operations
- Separating application responsibilities
- Reusable code components

Using OOP helps organize the application and makes further development easier.


## Project Purpose

This project was created to improve practical Python programming skills through the development of a mathematical application.

The main learning objectives were:

- Practicing Object-Oriented Programming
- Implementing mathematical calculations
- Developing graphical user interfaces
- Working with Python libraries
- Creating geometric visualizations
- Improving code organization and readability
